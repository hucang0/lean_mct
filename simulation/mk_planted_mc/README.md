# `simulation/mk_planted_mc/`: planted Monte Carlo of the Mari–Kurchan liquid

Metropolis Monte Carlo of the Mari–Kurchan (MK) random-shift hard-sphere model at λ = ∞, d = 3, started from planted
(exact equilibrium) configurations, and the analysis of its trajectories: self correlators, relaxation times,
plateaus, the bond-resolved pair-factorization test, the bond-conditioned decomposition, and the per-particle cage
covariance decomposition. Supports Letter Fig. 2(c,d) and SM Fig. S5, SM Sec. S4 A–E, Tables S7–S13, Figs. S3–S4.
CPU only (numpy, numba; `analysis.py --no-plots` avoids matplotlib).

| file | role | output |
|---|---|---|
| `mk_mc.py` | planted MC engine (numba, all-pairs overlap test, unwrapped positions, log-spaced frames from `--norig` time origins, checkpoints) | `run_phi<φ>_N<N>_s<seed>.npz` |
| `launch_mc.sh` | the 53 production runs: `A` (29 runs, φ = 0.80–2.00, into `data/`), `B` (24 runs, φ = 1.90–3.60, into `data_B/`) | |
| `analysis.py` | MSD, α₂, F_s(k,t) at k ≈ 3, 5, 7, 10, C(π,t), pair and triple chain correlators, factorization ratios R(t), τ, plateaus, power-law fits | `results/curves_averaged.json`, `plateau_table.json`, `tau_table.json`, `run_table.json`, `factorization_table.json`, `curves_*.npz` |
| `conditional.py` | bond-conditioned marginals F^c_i, F^c_j, R_marg, connected factor Γ = φ₂/(F^c_i F^c_j*), contact persistence | `results/reanalysis/conditional_summary.json` |
| `plateau_analysis.py` | per-trajectory lag curves and plateau-window cage covariances C_i: f_meas, f_G, isotropic and anisotropic Gaussian mixtures | JSON (path given) |
| `bias_null.py`, `bias_null_lib.py` | iid-Gaussian null test of the mixture estimator (bias correction) | stdout |
| `splithalf.py` | split-half check of the cage decomposition | stdout |
| `lag_summary.py` | MSD(τ) and its last-decade log-slope from `plateau_analysis.py` output (drift check at φ = 1.8, 1.9) | stdout |
| `collect_sim.py` | plateau MSD, f_s(k) and bias-corrected mixture per density, mean ± s.d. over samples | `results/sim_summary.json` |

The shipped results are in `../../data/simulation/results/` (`curves_averaged.json`, `plateau_table.json`),
`../../data/simulation/reanalysis/conditional_summary.json` and `../../data/restore/sim_summary.json`. Trajectories
are not shipped (0.9 GB); they are regenerated by `launch_mc.sh`.

## Reproduce

    bash launch_mc.sh A && bash launch_mc.sh B
    # Each batch runs jobs in parallel, waits for all children, and fails if any job fails.
    # set A: Tables S7-S12, Figs. S3-S4, Letter Fig. 2(c,d)
    python3 analysis.py --data data --out results --figures figures --nproc 8
    python3 conditional.py --data data --tau-table results/tau_table.json --out results/reanalysis --nproc 8
    # plateaus at ten densities (window t >= 10^3 sweeps): Table S13, SM Fig. S5
    F="data/run_phi1.80_N1000_s*.npz data/run_phi2.00_N1000_s*.npz data_B/run_phi*_N1000_s*.npz"
    python3 plateau_analysis.py 1000 1e9 results/plateau_final.json $F
    python3 lag_summary.py results/plateau_final.json
    python3 bias_null.py 1000 1e9 $F
    python3 splithalf.py 1000 1e9 data/run_phi1.80_N1000_s*.npz data/run_phi2.00_N1000_s*.npz
    python3 collect_sim.py --out results/sim_summary.json $F

Runtimes: each MC run 1–2 h on one core; `analysis.py` and `conditional.py` a few minutes each on 8 cores; the
plateau scripts seconds to minutes. Numba compiles the kernels on first use (cached in `__pycache__/`).

The analysis can be tried in seconds on a tiny system; `../../examples/smoke_d_bond_factorization.py` runs
`mk_mc.py` (N = 300, φ = 1.5, 3000 sweeps, two samples) → `analysis.py` → `conditional.py` and recovers
R∥(τ₇) ≈ 2.5 and Re Γ∥ ≈ 1.8 (SM Table S12, N = 1000: 2.54 and 1.81).

## Conventions

N_p particles of diameter 1 in a periodic box, ρ = N_p/L³, φ = πρ/6; pair (i, j) interacts through the shifted
separation r_ij = MI(x_i − x_j − A_ij) with quenched uniform shifts A_ij = −A_ji. One sweep = N_p attempted moves
(cubic proposal of half-width δ = 0.10). The centre-of-mass drift is removed per frame. Contact pairs: |r_ij| < 1.05
at the time origin; k along the bond: k = k₇ r̂_ij with |k₇| ≈ 7 on the lattice 2πn/L.
